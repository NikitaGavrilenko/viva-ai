# Viva AI

Адаптивный тренажёр устного экзамена по учебным материалам. Проект создаётся
для онлайн-хакатона **Prometheus July AI Challenge 2026**.

Пользователь загружает PDF или конспект, отвечает на вопросы своими словами,
а Viva AI:

- оценивает смысл ответа по исходному материалу;
- показывает сильные стороны и конкретные пробелы;
- задаёт адаптивный следующий вопрос;
- формирует персональный план повторения с цитатами из источника.
- переключается между русским и английским интерфейсом;
- генерирует вопросы и обратную связь на выбранном языке, сохраняя цитаты
  в оригинале.

## Почему здесь нужен AI

Обычный тест сравнивает ответ с заранее заданным вариантом. Viva AI проверяет
свободные объяснения, учитывает эквивалентные формулировки и меняет траекторию
опроса в зависимости от обнаруженных пробелов. При этом модель ограничена
загруженным материалом, а ответы проходят проверку Pydantic-схемами.

## Как рассчитывается оценка

Модель не выставляет итоговый балл. Она отдельно сопоставляет каждый ожидаемый
пункт с ответом студента:

- `met` — раскрыт полностью: 1 балл;
- `partial` — раскрыт частично: 0,5 балла;
- `missing` — отсутствует или неверен: 0 баллов.

Python рассчитывает итог как долю набранных баллов от числа критериев. Поэтому
одинаковая комбинация выполненных критериев всегда даёт одинаковую оценку.
Интерфейс показывает статус и объяснение по каждому пункту.

## Быстрый запуск

Требуется Python 3.10+. Основной режим работает локально через
[Ollama](https://ollama.com/) и не требует API-ключа.

```powershell
D:\Anaconda3\envs\ml\python.exe -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Установите или запустите локальную модель:

```powershell
ollama pull qwen3:14b
```

Затем запустите приложение:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Приложение автоматически обнаружит установленные модели Ollama. Для первой
демонстрации выберите `qwen3:14b` и встроенный конспект по машинному обучению.

Облачный OpenAI-совместимый API остаётся доступен как дополнительный режим.
Его адрес, модель и ключ можно задать в боковой панели или через `.env`.

## Главный демо-сценарий

1. Открыть Viva AI и выбрать встроенный материал.
2. Начать экзамен.
3. Дать неполный ответ на первый вопрос.
4. Показать оценку, цитату и адаптивный уточняющий вопрос.
5. Ответить точнее и перейти к новой теме.
6. Завершить сессию и показать персональный план повторения.

## Возможности интерфейса

- быстрый экзамен на 3 вопроса или полный на 5;
- три уровня сложности: базовый, стандартный и продвинутый;
- мгновенный старт встроенной демонстрации без ожидания генерации первого вопроса;
- просмотр исходного фрагмента рядом с вопросом;
- повторная попытка, пропуск вопроса и досрочное завершение;
- адаптивная смена темы или точечный уточняющий вопрос по обнаруженному пробелу;
- итоговая карта освоения тем и скачиваемый Markdown-отчёт;
- полноценный интерфейс и ответы экзаменатора на русском или английском.

## Архитектура

```text
PDF / TXT / MD
      |
      v
извлечение и нормализация текста
      |
      v
смысловые фрагменты + простой поиск контекста
      |
      v
LLM: вопрос -> оценка -> адаптивный следующий вопрос
      |
      v
Pydantic-валидация -> Streamlit UI -> итоговый план
```

- `app.py` — интерфейс и состояние экзамена;
- `viva_core.py` — загрузка материала, поиск контекста, LLM-клиент и схемы;
- `demo_materials/` — безопасный встроенный материал для демонстрации;
- `tests/` — тесты детерминированной логики без обращения к API.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m py_compile app.py viva_core.py
.\.venv\Scripts\python.exe scripts\evaluate_grading.py
```

Последняя команда запускает медленную golden-проверку локальной модели:
баллы для неправильного, общего, частичного и полного ответов не должны
убывать, частичный ответ должен попасть в диапазон 40–80, а два одинаковых
полных ответа — получить 100.

## Ограничения MVP

- PDF должен содержать текстовый слой; OCR пока не реализован.
- Локальный и облачный режимы используют совместимый формат `/chat/completions`.
- Для очень больших документов берётся репрезентативная выборка фрагментов.
- Качество вопросов и оценивания зависит от выбранной модели.
- Пользователь должен самостоятельно проверить важные учебные выводы.

## Безопасность и приватность

В локальном режиме материал обрабатывается Ollama на компьютере пользователя.
В облачном режиме он отправляется выбранному LLM-провайдеру, поэтому не следует
загружать приватные данные без проверки его условий. API-ключи не сохраняются
приложением и исключены из Git через `.gitignore`.
