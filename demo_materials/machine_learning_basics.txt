MACHINE LEARNING BASICS

Machine learning is a field of artificial intelligence in which algorithms discover patterns in data and use them to make predictions or decisions without explicitly programming every rule.

Supervised learning uses labeled data: every example has a known target. In classification, the target is a category such as "spam" or "not spam." In regression, the target is a numeric value such as the price of an apartment.

Unsupervised learning works with data that has no predefined targets. A common task is clustering, which groups similar objects together. Dimensionality reduction creates compact representations of data and can support visualization.

A dataset is usually divided into training, validation, and test subsets. The model learns its parameters from the training subset. The validation subset is used to choose hyperparameters and compare alternatives. The test subset should be used only for the final independent evaluation.

Overfitting occurs when a model memorizes the training examples but performs poorly on new data. Typical signs are low training error and substantially higher validation or test error. Regularization, simpler models, additional data, data augmentation, and early stopping can reduce overfitting.

Common classification metrics include accuracy, precision, recall, and F1. Accuracy is the fraction of all predictions that are correct. Precision is the fraction of predicted positive examples that are actually positive. Recall is the fraction of all true positive examples found by the model. F1 is the harmonic mean of precision and recall. With a severe class imbalance, accuracy can be misleading, so precision, recall, F1, and the confusion matrix provide a more useful picture.

Data leakage occurs when training uses information that would not be available at inference time, or when information from the test subset influences training. For example, normalizing the full dataset before splitting allows test-set statistics to affect the training process. Transformations should be fitted on the training subset and then applied to the validation and test subsets.
